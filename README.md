# WoW Forever Addons

A collection of addons developed for **WoW Forever**. Each addon lives in its own directory so it can be maintained and released independently.

## Addons

### [ProfessionBars Forever](ProfessionBarsForever/)

Configurable progress bars for professions and character skills, with recipe browsing tools.

**Current version:** 1.0

See the [addon README](ProfessionBarsForever/README.md) for features, installation, and usage.

## Repository layout

Each addon has its own folder containing the game-loadable files and its documentation. To install an addon, copy only that addon's directory into your WoW `Interface/AddOns` directory.
